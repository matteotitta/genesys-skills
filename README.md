# genesys-skills

![Skills](https://img.shields.io/badge/skills-10-6400D7) ![Stars](https://img.shields.io/github/stars/matteotitta/genesys-skills?color=6400D7&labelColor=181723) ![License](https://img.shields.io/badge/license-MIT-BAFDFF?labelColor=181723)

**Ten free Claude Code skills for B2B SaaS product marketing.** Research a company and its competitors, find its ICP, pin down positioning and tone of voice, then plan a launch, write a case study, build a battlecard, plan AEO content and fix a LinkedIn profile. Each one runs on its own: copy the folder in and go.

I'm [Matteo Titta](https://github.com/matteotitta), founder of [Genesys Growth](https://genesysgrowth.com). These are lite versions of skills I run on client work every week.

## The 10 skills

| Skill | What it does |
|---|---|
| [company-context](skills/company-context/SKILL.md) | Researches a company from its URL: funding, team, traction, hiring, plus a qualification score and red flags |
| [icp-research](skills/icp-research/SKILL.md) | Builds an ICP from the company's own case studies, testimonials and solutions pages |
| [competitor-research](skills/competitor-research/SKILL.md) | A 13-dimension dossier on one competitor, with sources and confidence levels |
| [positioning](skills/positioning/SKILL.md) | Maps alternatives and anchors, lays out 2-3 positioning options side by side, then locks the one you pick |
| [tov-guidelines](skills/tov-guidelines/SKILL.md) | Pulls a company's tone of voice out of its existing content and turns it into usable guidelines |
| [product-launch](skills/product-launch/SKILL.md) | Turns a launch brief into a tier, a set of tactics, the assets and a timeline |
| [case-study](skills/case-study/SKILL.md) | Writes a challenge, solution and results case study from verbatim quotes and verified numbers |
| [battlecards](skills/battlecards/SKILL.md) | One battlecard per competitor that a rep can actually use on a call |
| [aeo-strategy](skills/aeo-strategy/SKILL.md) | Plans what to publish so ChatGPT, Perplexity and Google AI cite you |
| [linkedin-profile](skills/linkedin-profile/SKILL.md) | Scores a LinkedIn profile section by section, then rewrites it |

## How to use one

1. Copy a skill folder into `.claude/skills/` in your project.
2. Open Claude Code and ask for it by name, for example "run company-context on acme.com".
3. Read the output, push back where it's wrong, and run the next one.

## Lite versions

These carry the method: when to run, what to feed in, the steps and the quality bar. The full versions add the reference libraries, output templates and worked examples behind each step, so where a skill says "the premium reference", that part lives in the full version.

The full skills come packaged as plugins with recommended MCP servers and paired agents, and students on [Marketing Engineering University](https://maven.com/matteo-tittarelli/marketing-engineering-university-genesys-growth) get them all.
